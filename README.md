# 保有株ブリーフィング・ダッシュボード

毎朝の保有株チェックを補助する、自己完結型 HTML ダッシュボードです。
`portfolio.csv` をインプットに、yfinance（ブロック時は `news.json` 内のスナップショットへフォールバック）で価格を取得し、ニュース・観察ポイントを付して `index.html` を生成します。

> ⚠️ **免責**: 本ツールは個人の判断補助を目的とした情報集約ダッシュボードであり、投資推奨ではありません。
> 表示される分類・コメントは機械的なルール（損益率の閾値とキーワードマッチ）に基づくもので、最終的な売買判断はご自身の責任で行ってください。

## 構成

| ファイル | 役割 |
|---|---|
| `portfolio.csv` | 保有銘柄のマスタ（UTF-8 / `銘柄コード,銘柄名,保有株数,取得単価,取得日`） |
| `news.json` | 銘柄ごとの直近ニュース・観察ポイント・価格スナップショットを格納する手元 DB |
| `build.py` | CSV/JSON を読み、yfinance で価格を引き、`index.html` を生成するメインスクリプト |
| `index.html` | `build.py` の出力（インライン CSS/JS のみ、外部依存なし） |
| `requirements.txt` | Python 依存（yfinance, pandas） |

## 再生成手順（毎朝の運用）

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python build.py
git add index.html news.json
git commit -m "update: morning briefing"
git push
```

GitHub Pages を有効化（Source: branch / `/ (root)`）しておけば、push 後 1〜2 分で公開ページが更新されます。

ニュース欄を最新化したいときは `news.json` を編集してから `python build.py` を再実行してください。各ニュース項目は **タイトル / 出典名 / 公開日(YYYY-MM-DD) / URL** の 4 項目すべてが揃っているもののみ採用されます（欠けていれば自動で除外）。

## 分類ロジック（透明性のため公開）

ルールは `build.py` 冒頭の定数で定義しています。閾値・キーワードは状況に応じて編集可能です。

| バッジ | 条件 |
|---|---|
| 🔴 **売却検討** | 損益率 ≦ **−15%**、または **重大ネガティブキーワード**（不祥事級）にヒット、または **注意キーワード** ＋ 損益率 ≦ 0% |
| 🟡 **様子見** | 損益率が **−15% より上、0% 以下**、または **注意キーワード**にヒット（含み益でも） |
| 🟢 **継続保有** | 損益率 > **0%** かつ懸念ニュースなし |

### キーワード辞書

- **重大ネガティブ（severe）**: `不正` / `架空` / `粉飾` / `不適切取引` / `違反` / `経営悪化` / `巨額損失`
- **業績注意（mild）**: `下方修正` / `減益` / `リコール` / `業績悪化` / `訴訟` / `減配` / `減産`

各カードには **「分類根拠」** セクションを必ず表示し、損益率・ヒットしたキーワード・閾値判定の根拠を明示します。

## エラー耐性

- 1 銘柄の価格取得に失敗しても他の銘柄の処理は継続します。失敗した銘柄は `取得失敗` バッジ付きのカードとして表示されます。
- `yfinance` から価格が取れない場合（ネットワーク制限・API変更等）は `news.json > price_snapshot.prices` の手動スナップショットへフォールバックします。
- 4 項目（タイトル/出典/日付/URL）のいずれかが欠けたニュースは採用しません（出典不明な記述を防ぐため）。

## 著作権・引用方針

ニュースは **タイトル＋元記事へのリンク＋自分の言葉での 1〜2 行要約** のみを表示し、本文の長文引用は行いません。出典名と公開日を明示し、元記事への導線を必ず設けます。
